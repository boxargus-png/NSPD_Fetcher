# Изменения NSPD Fetcher

## 0.1.1 — подготовка к проверкам каталога

Подготовлен 17.10.2026 после автоматической проверки первого архива.

- Для случайной паузы между запросами используется системный источник случайности; диапазон задержки и отмена сохранены.
- Ошибки записи файла журнала и панели QGIS передаются стандартному журналу Python вместо молчаливого подавления. Недоступность одного назначения не останавливает остальные.
- Устранено замечание стиля в проверке первого открытия окна.
- Цепочка МСК, пространственный отбор и результаты загрузки не изменены.

## 0.1.0 — первый экспериментальный выпуск

Подготовлен 17.10.2026. Исходники: [boxargus-png/NSPD_Fetcher](https://github.com/boxargus-png/NSPD_Fetcher).
Архив загружен в каталог QGIS 17.10.2026; автоматическая проверка заблокировала
версию из-за генератора случайной задержки и подавления ошибок журнала.
Замечания исправлены в 0.1.1.

- Загрузка НСПД по нарисованному охвату, геометриям векторного слоя или кадастровым номерам.
- Запросы через сетевые средства QGIS с его настройками прокси, TLS и таймаута; отмена активного запроса и проверка структуры ответа.
- Сохранение уже полученных объектов при ошибке или отмене во временные слои; неполные результаты помечаются явно.
- Удаление дублей только при совпадении категории, ID, геометрии, атрибутов и дополнительных полей исходной записи.
- Поисковый буфер около 5 м; локальный отбор по исходному охвату после согласования координат, до округления.
- Один выбор МСК результата; автоматическое создание промежуточной CRS ГОСТ 2001 с сохранением прежней цепочки преобразования.
- Компактная форма, прозрачное рисование охвата, контур и зелёная индикация готовности, приближение к охвату.
- Подробный прогресс: запросы, полученные и отобранные записи, ошибки, паузы, прошедшее время и создание слоёв.
- Установочный ZIP с явным списком файлов, лицензией, документацией и отдельной контрольной суммой.

Минимальная версия — QGIS 3.40, ветка 3.x. Проверено на Windows / QGIS 3.40.4.
Linux и macOS пока не проверялись, QGIS 4 не поддерживается. Дополнительные
пакеты Python не требуются. Нужны интернет и провайдер Processing `native`.

Регрессионный участок `52:18:0050232:698` проверяет сохранение прежнего результата
МСК до сантиметра. Слои временные; их сохранение на диск выполняет пользователь.
